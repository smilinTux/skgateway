# secrets/

Nothing real in this directory is committed. `.gitignore` excludes everything
here except `*.example` files and this README.

## codex-auth.json

The Codex CLI credential for the ChatGPT subscription backend. It is **not**
generated by this repo: it is a copy of the Codex CLI's own `auth.json`,
synced by `sync-codex-auth.sh` and refreshed on a timer
(`skgateway-codex-auth-sync.timer`).

To set up a new instance:

```sh
cp secrets/codex-auth.json.example secrets/codex-auth.json
chmod 600 secrets/codex-auth.json
# then populate it from the Codex CLI auth on the authenticated host,
# or let sync-codex-auth.sh do it
```

`OPENAI_API_KEY` is `null` on purpose in subscription mode. The gateway
authenticates with the token set rather than an API key, and setting both is a
configuration error.

## Why the example file exists

`secrets/` was not gitignored at all until 2026-08-27. A live credential sat one
`git add -A` away from being committed for the lifetime of the directory. The
fix is two-sided and both halves matter: ignore the real files so they cannot be
committed by accident, and commit an example so the required shape is
discoverable without anyone needing to open the real one.

Mode `0600` is not decoration. The sync timer writes it that way and the gateway
expects it.

- `POST /v1/responses` is now an inbound OpenAI Responses frontend: requests are translated to chat completions and run through the normal pipeline (routing, buckets, sanitizer, failover, audit), then translated back, streaming and not. Codex CLI (which only speaks Responses) can use any gateway model, including sk-* buckets whose backends only speak chat. Before, the path was passed straight to the backend: streaming answered 502 `empty_upstream_response` and a Codex-shaped request 404. The gateway stores nothing, so `previous_response_id` and `conversation` are a 400.

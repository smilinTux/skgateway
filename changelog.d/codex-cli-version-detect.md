- codex: the reported Codex CLI version now follows the installed `codex --version` when it is newer than the built-in default, which is bumped to 0.170.0 (the backend lists gpt-6.2-sol and gpt-6.2-astra only for client_version >= 0.170.0). `SKGATEWAY_CODEX_CLI_VERSION` still pins it; `SKGATEWAY_CODEX_BIN` names the binary and `SKGATEWAY_CODEX_CLI_DETECT=off` skips the probe. Startup logs the version in use and its source. Closes #219.
  The probe result is cached per process, so a codex upgrade takes effect on the next gateway restart. Under systemd the unit PATH usually lacks `~/.local/bin` and npm global bins; the startup log then says "codex not found, set SKGATEWAY_CODEX_BIN".

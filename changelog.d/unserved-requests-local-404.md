- Requests with no model and no `x-sk-context`/`x-sk-service`/`x-sk-role` header are answered by the gateway instead of the routing default: outside `/v1`, or as a GET/HEAD, a local 404 `not_found`; any other under `/v1`, 400 `model_required`; each logged as a `request.unserved` audit event. Requests that name a model are unchanged on every path. Before, Hermes' local-server fingerprint probes (`/api/tags`, `/props`, `/v1/props`, `/version`, `/api/v1/models`, `/api/show`) reached codex on chi (about 2,500 a week, `upstream_error backend=codex {"detail":"Not Found"}`) and nvidia on nor; of about 14,900 model-less requests across both estates since 2026-09-05, one ever succeeded. A body that names a model is still routed when sent without a JSON content type. Also removes a duplicate, unreachable codex branch in the router's backend dispatch chain.
